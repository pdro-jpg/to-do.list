# To-Do List em Java (Console)

Um projeto simples para praticar os fundamentos da linguagem Java e Programação Orientada a Objetos (POO) através de um gerenciador de tarefas de linha de comando.

#  Funcionalidades 
Este projeto permite ao usuário gerenciar tarefas de forma simples, utilizando apenas a entrada e saída de dados via console. As principais funcionalidades incluem:

-> Adicionar Tarefa: Inserir novas tarefas na lista.

-> Listar Tarefas: Exibir todas as tarefas com seus respectivos status ([X] ou [ ]).

-> Marcar como Concluída: Alterar o status de uma tarefa específica.

-> Remover Tarefa: Excluir uma tarefa da lista.

#  Tecnologias Utilizadas 
-> Linguagem: Java

-> Estruturas de Dados: ArrayList para gerenciar a coleção de tarefas.

-> Programação Orientada a Objetos (POO): Utilização das classes Tarefa (modelo) e ListaDeTarefas (gerenciador).

#  Como Executar 

1 - Clone o Repositório:

```Bash```

```git clone https://github.com/pdro-jpg/to-do.list.git```

```cd to-do.list```

2 - Compile e Execute (Java Puro) : Se você não estiver usando Maven ou Gradle, use os comandos nativos do JDK:

```Bash```

```javac Task.java TaskList.java Main.java```

```java Main```

3 - Interaja com o Menu: O programa iniciará um menu no console. Digite o número da opção desejada (1, 2, 3, 4 ou 0) e pressione Enter.
